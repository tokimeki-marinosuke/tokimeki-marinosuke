## Shared hacker theme

All 42 displayed icons use local SVG tiles with a black/deep-green diagonal gradient and a green outline. Vector tile backgrounds from Skill Icons have been replaced; logo artwork retains its original colors except the dark JavaScript lettering, which uses its familiar yellow for contrast. Supplied raster logos remain embedded intact inside the rounded frame.

- [Skill Icons](https://github.com/tandpfun/skill-icons): MIT; see `SKILL-ICONS-LICENSE.txt`.
- MATLAB and Node-RED: [Devicon](https://github.com/devicons/devicon); see `DEVICON-LICENSE.txt`.
- Claude: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg); see `SIMPLE-ICONS-LICENSE.txt`.
